# docs

Proje geneli dokumanlar.

| Dosya            | Icerik                                                                        |
|------------------|-------------------------------------------------------------------------------|
| ARCHITECTURE.md  | Acilis akisi, bellek haritasi, BootInfo, bagimlilik grafigi, kurallar          |
| MODULES.md       | Tum modullerin tek satirlik ozeti ve nereye bakilacagi                         |

Modullere ozel ayrintilar ilgili klasordeki README.md dosyalarindadir; buradaki dosyalar sadece genel resmi verir.
Yeni bir modul veya onemli bir degisiklik eklediginde ARCHITECTURE.md'deki bagimlilik grafigini ve MODULES.md'yi guncelle.
